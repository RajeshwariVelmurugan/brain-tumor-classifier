# Brain Tumor Classifier with AI Chatbot & Voice

A deep learning web app that can:
- **Classify brain MRI scans** into four categories: glioma, meningioma, pituitary tumor, or no tumor.
- **Answer any medical question** about brain tumors using Google Gemini AI.
- **Read the answers aloud** with text‑to‑speech (gTTS).

**Test Accuracy:** 86.82% on unseen data.
